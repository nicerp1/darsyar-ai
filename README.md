# روند مطالعه (Ravand Study)

روند مطالعه یک برنامه‌ریز درسی فارسی برای دانش‌آموزها و مشاورهای تحصیلی است. این پروژه پیش‌تر با نام «درس‌یار» منتشر شده بود.

- [سایت رسمی روند مطالعه](https://ravandstudy.ir/)
- [ورود به برنامه‌ریز روند](https://app.ravandstudy.ir/)
- [راهنمای ساخت برنامهٔ مطالعهٔ هفتگی](https://ravandstudy.ir/study-planner)

کاربران می‌توانند برنامهٔ روزانه و هفتگی بسازند، زمان مطالعه را ثبت کنند، نکته‌ها را با فلش‌کارت مرور کنند و با تایمر تمرکز یا در اتاق مطالعهٔ آنلاین درس بخوانند.
